# Noema Design System

## Direction

Gruvbox dark-first, warm, and information-led. Paper grain is static and subtle; amber, red, and green remain semantic. Gruvbox light is the only alternate theme.

## Color

All implementation colors use semantic tokens. Core roles: warm background, raised surfaces, high-contrast ink, amber action, warning, error, success, code, paper, and focus. Light mode preserves the same roles.

## Typography

One system sans stack. Fixed product scale from `0.75rem` metadata to `1.75rem` page title. Monospace is reserved for shortcuts and code.

## Shape and Depth

Controls use `8px`; surfaces use `12–14px`. Depth comes from surface lightness and hairline borders, not large shadows or glass effects.

## Layout

Desktop: `224px` navigation, flexible timeline, `320px` attention rail. Mobile: stacked priority flow with fixed bottom navigation and safe-area padding.

## Motion

State transitions run `160–220ms` with ease-out. Reduced-motion disables nonessential transitions.
