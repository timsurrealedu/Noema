# Product

## Register

product

## Platform

web

## Users

Personal-first for a self-hosting power user managing study, knowledge, schedules, tasks, coding agents, and automations across desktop and mobile.

## Product Purpose

Noema turns unstructured input into connected knowledge, action, or schedule while preserving sources, reviewability, and user control.

## Positioning

Capture anything; Noema places it in the right context without making the user choose a module first.

## Brand Personality

Calm, intuitive, and technical. Pages show only what matters now, with detail available on demand.

## Anti-references

Not a corporate analytics dashboard, generic AI chatbot, sci-fi control panel, playful widget collection, or set of mini-apps.

## Design Principles

- Capture before categorization.
- Make AI interpretation visible and reversible.
- Keep sources and relationships close to generated objects.
- Prioritize attention, not volume.
- Adapt structure—not merely size—across devices.

## Accessibility & Inclusion

Target WCAG 2.2 AA: keyboard access, visible focus, semantic structure, non-color state cues, reduced motion, adequate contrast, and 44px touch targets.
